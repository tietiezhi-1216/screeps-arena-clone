## v0.12.0

### 电脑对手：6 个等级
- 入门 / 简单 / 普通 / 困难 / 专家 / 大师，可以在每个模式里任选。
- 等级越高越聪明：出兵更快、兵更大、很少“发呆”；逐级学会用塔、远程边打边退、优先给残血加血、集火残血目标、残血撤回治疗身边、看对手兵种调整编队、记住冰冻/伤害区域绕着走、运输兵绕开敌塔和敌兵。
- 电脑只用游戏官方提供的功能，和玩家能用的积木完全一样。
- 自动循环赛里，每个高等级对每个低等级、在每个模式下都赢多输少。

### 模式
- 不再分“基础 / 高级”，每个模式只有一个版本（采用规则更完整的那一版）。
- 新模式「三路推塔」：上中下三条路，每方 7 座会自动开火的防御塔，拆掉对方基地获胜。
- 新模式「山头争夺」：占住地图中央的旗帜，旗帜旁只有你的兵时每回合得 1 分，先到 300 分获胜。
- 两个新模式都有新封面，用的是游戏里真实的画面。

### 画面
- 兵会转身：移动时平滑转向前进方向，停下来保持朝向。
- 身体部件的画法和官方一致：移动部件在后面，攻击、远程、治疗、工作等部件在前面居中、左右对称排开。
- 兵和基地中间显示主人的徽章，基地上方显示玩家名字。

### 个人中心
- 首页新增「个人中心」：修改名字、选择徽章图案和颜色，查看对局数、胜场、胜率和各模式战绩（会记录你打赢过的最高电脑等级）。

### 注意
- 旧脚本仍然可以用；原来标着“基础 / 高级”的脚本现在统一对应同一个模式。
