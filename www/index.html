局域网联机

   
同一 WiFi（或热点）下：一台开房当玩家 1，另一台加入当玩家 2，其余加入者观战。房主权威模拟，实时同步。

   
   

   

   

   

   
回放

   
应用

   
API 速查（对齐 arena.screeps.com/docs）

   
脚本是 ES 模块，导出 loop()，每 tick 调用一次；可导入 game/utils、game/prototypes、game/constants、game/path-finder、game/visual、game。

   
CPU：每 tick 50 ms，首 tick 1000 ms；超时则该 tick 的指令全部作废。脚本无法访问网络、存储与全局对象，eval/Function 被禁用。

   
非官方项目，与 Screeps Arena 开发商无关。
